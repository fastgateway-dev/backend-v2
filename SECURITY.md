# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in FastGateway, please report it
privately — **do not open a public GitHub issue**. Public issues are visible
to everyone immediately, including potential attackers, before a fix is
available.

Instead, please report it using [GitHub Security Advisories](../../security/advisories/new)
for this repository ("Security" tab → "Report a vulnerability"). This creates
a private advisory visible only to the maintainers and lets us coordinate a
fix and disclosure timeline with you before anything is made public.

Please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept
- The affected version(s) or commit
- Any suggested mitigation, if you have one

## What to Expect

- We will acknowledge your report as soon as possible.
- We will investigate and keep you updated on progress toward a fix.
- Once a fix is available, we will coordinate with you on disclosure timing
  and credit (if desired) before publishing details publicly.

## Scope

This policy covers the FastGateway backend in this repository. For
vulnerabilities in the frontend, please report them via the same process in
the [`fastgateway-dev/frontend-v2`](https://github.com/fastgateway-dev/frontend-v2)
repository.

Thank you for helping keep FastGateway and its users safe.
